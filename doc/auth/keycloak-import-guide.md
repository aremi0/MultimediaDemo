1. Accedi alla Dashboard di Keycloak tramite browser su `https://multimedia-entrypoint/`
2. Seleziona il realm `multimedia-realm` o crealo se non esiste
3. Selezionare "Realm Settings" dal menu a sinistra
4. Selezionare "Partial Import" dal pulsante in alto a destra, valorizzato di default con il valore "Action"
5. Draggare il file `realm-export.json`
6. Selezionare tutti i "client", "realm-roles" e "client-roles"
7. Selezionare "Overwrite"
8. Cliccare su "Import"
